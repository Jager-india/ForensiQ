# `q_voice` — Investigator & Auditor User Guide

## 1. Investigative Workflow
1. **Audio File Ingest:** Import Voice Recordings, dictaphone files, or call center WAV/MP3 streams.
2. **Review Auto-Transcripts:** Search across conversational transcripts for secret terms or off-the-record references.
3. **Analyze Intent Flags:** Filter conversations where speech analytics tagged intent flags such as `Concealment`, `Kickback Agreement`, or `Alibi Coordination`.
4. **Export Dossier Snippets:** Clip synchronized audio and text transcripts for investigative court evidence.
